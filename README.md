# R Programming Lab — ITA0407 / ITA04 (Statistics with R Programming)

RStudio-style screenshots and runnable source for the first 10 lab experiments.

Each screenshot in `screenshots/` is laid out like RStudio (editor + Environment +
Console + Plots panes). The console output and environment values are real — the code
in `scripts/` was run on **R 4.3.3** and the output captured.
